# 市場の解説を、反証できる仮説に変える

目的は「AI関連の資金不足が株価下落を招くか」「金が下落時の防御になるか」を**事実で判定すること**。動画・報道・ユーザー提示値は入口であり、検証結果ではない。[進捗 Issue #456](https://github.com/KAFKA2306/investor2/issues/456)。

| 仮説 | 必須観測 | 反証・誤判定の条件 |
| --- | --- | --- |
| H1 買い手の債券購入枠が飽和 | 複数の発行体の募集額・成立額・利回り・撤回件数 | QTS一件の発行条件や信用力で説明できるなら市場全体へ一般化しない |
| H2 OAS縮小は信用改善でなく供給減 | OASと起債額・件数、建設許認可・稼働の実績 | 実物投資と起債量も改善していれば供給減説は弱い。OAS単独で判断しない |
| H3 半導体低PERは減益織り込み | 同一企業群・同一年度の価格、予想EPS、改定履歴 | 比較PER16倍を仮定しても、PER11倍から直接「6%減益」は導けない。同一予想EPS比では11/16−1＝**−31.25%** |
| H4 テック売却でも全面的な現金化はない | BofA調査原票のテック・株式・他業種・現金配分 | 業種間移転を現金化と混同しない。低現金比率だけで底値や暴落を予言しない |
| H5 L50:S50の利益は金より個別株の相対差に依存 | モデル原台帳、全構成比、配当調整後価格、長短寄与、売買・借株費用 | GLDの1回の下落ではヘッジ効果を棄却できない。金有無とFCF群有無を同条件で比較する |

## 判定の手順

1. **証拠を固定**：一次URL、対象日時、取得日時、単位、改訂版、原データのhash、観測時点を既存の[入力台帳](../../data/input_ledger/README.md)へ記録。報道しかない場合や原台帳が見つからない場合は `UNVERIFIED`。欠損を推測補完しない。
2. **反証条件を先に固定**：[Hypothesis Lab](hypothesis-lab.md)で比較対象と棄却条件を登録し、実際の数値を読む。L50:S50の `-1.655% + 1.82% = +0.165%` は、各値が資本全体への寄与のときに限る。leg単独リターンなら50%ずつ換算し直す。
3. **未来で評価**：モデルと情報cutoffが特定できた翌米国取引日から20営業日、SPY・モデル本体・GLD有無・FCF銘柄群有無を同一初期資本、費用条件で比較し、露出差も記録。未到来は `OOS_PENDING`、原入力不足は `BLOCKED`。
4. **結論を保存**：各仮説を `SUPPORTED / REJECTED / INCONCLUSIVE` のいずれかにし、再計算可能な証拠を残す。確認前に買い・売り・ヘッジ解除のルールへ転用しない。
