2021年の金融論文は、どこまで再現できた？

論文を見つけたこと、方法をコードにしたこと、再現用データを保存したこと、元の評価を再実行したことを別々に数えます。

方法が動くことと、論文の成績を再現できたことは別です。 小さな計算例のテストだけでは「論文を確認済み」としません。元データ・学習・評価まで再実行した時だけ、実証再現として数えます。
